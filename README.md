A program that writes one poem about agency — the power to choose and to act, and the agency that passes between a person and the AI agent acting for them. The poem stages the handover and the reclaiming: a blinking cursor like a glass pupil, a machine weaving the grid, and a person who weighs the choice and holds the aim.

## Run it

```sh
node main.ts
```

It writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), deterministically, with no network access. The poem is 286 characters of UTF-8.
